# Pet Desktop

Um bichinho de IA que vive na sua tela (Windows).

- **Site:** https://pablo137-pixel.github.io/downlouad/
- **Baixar:** aba **Releases**. `PetDesktop-Beta.exe` é grátis; `PetDesktop-Pro.exe` precisa de licença.
- Confira a integridade com o `SHA256SUMS.txt` de cada release.

Este repositório tem só o site e os downloads. O código-fonte é proprietário (veja LICENSE.txt).
